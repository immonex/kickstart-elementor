Das [Team-Add-on für Kickstart](https://de.wordpress.org/plugins/immonex-kickstart-team/) enthält ein [einheitliches Kontaktformular](https://docs.immonex.de/kickstart-team/#/komponenten/kontaktformular) für objektbezogene Anfragen und allgemeine Nachrichten an Immobilienmakler.

Mit diesem Widget kann die in den Add-on-Plugin-Optionen unter ***immonex → Einstellungen → Team<sup>ADD-ON</sup> → Kontaktformular*** hinterlegte Bestätigungsmeldung eingebunden werden, sofern die ID der betr. Seite im gleichen Tab als Weiterleitungsziel nach erfolgreichem Versand der Formulardaten definiert wurde.
